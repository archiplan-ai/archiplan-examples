# Мобильный кошелек для фиатных платежей по QR кодам

Этот проект демонстрирует результат одной быстрой итерации по дизайну кошелька с Claude Opus 4.6 xhigh вооруженным Archiplan CLI. Агенту был дан короткий промпт с постановкой проблемы и инструкции действовать автономно. По результатам итерации агент написал [отчет](./ARCHITECTURE.md) используя зания о проекте зафиксированные в Archiplan.

**Промпт:**
```
Спроектировать мобильный кошелёк, который позволяет пользователю расплачиваться в локальной фиатной валюте по QR-кодам мерчантов в Тайланде, Вьетнаме, Бразилии и по интероп-схемам в остальных странах. Пополнение баланса через депозит USDT.
```
